## Native tests

`test/test_integrate_lebedev.f90` passed **56,735 assertions**, including
**56,033 polynomial moments**, in checked `-O0` and optimized `-O3` builds.
The tests cover all 32 orders and node counts, finite data, unit-sphere
coordinates, surface weight normalization, signed weights, odd moments,
every inequivalent even moment through each rule's algebraic order, and
additional highest-degree coordinate permutations. They also check low-order
reference values, exponential-integral convergence, complex-valued sums,
replacement of allocated outputs, all unsupported orders between -2 and 132,
the largest default integer, recovery after invalid input, and omitted status.

## Independent comparisons

`validation/check_lebedev.py` and `validation/lebedev_reference_driver.f90`
passed in both builds:

- All **32** rules, including the largest 5810-node rule.
- **140,928** coordinate values and **46,976** weights compared with SciPy.
- **281,856** reflection, inversion, and coordinate-permutation checks,
  including paired-weight equality and node uniqueness.
- **56,033** analytic polynomial moments, plus selected nonconstant zonal
  spherical harmonics through each rule's order.

Coordinate comparison uses absolute tolerance `4*epsilon` with zero relative
tolerance; weights use relative tolerance `8*epsilon` with zero absolute
tolerance. Unit-length errors are bounded by `4*epsilon`; surface-weight sum
errors by `5e-13`. Symmetry lookup rounds coordinates to 14 decimal places
and requires exactly equal weights on equivalent nodes. Legendre integrals
use absolute tolerance `1e-13` around their exact value zero.

The even moment formula is

```text
integral_S2 x^(2a) y^(2b) z^(2c) dS
    = 4*pi * (2a-1)!! (2b-1)!! (2c-1)!! / (2(a+b+c)+1)!!
```

Native tests evaluate finite product ratios without factorial overflow.
The Python oracle independently constructs exact rational factorial ratios
using Python integers and `fractions.Fraction`, converting to binary64 only
at the end. Each check uses the bound
`3e-13*exact + 16*epsilon*sum(abs(weighted_terms))`, accounting for relative
accuracy and signed-weight cancellation. The maximum observed relative moment
error was approximately **3.837e-15** in both configurations. Symmetry reduces
all polynomial moments to the tested inequivalent even cases; odd moments
vanish by reflection. The mathematical reference is the simplex beta integral
in [DLMF 5.14.2](https://dlmf.nist.gov/5.14.E2).

For version verification, the inspected `get_lebedev_sphere` and
`get_lebedev_recurrence_points` functions from the tagged 1.18.1 source were
evaluated and compared with installed SciPy 1.15.3. All coordinates and weights
were **bitwise identical for all 32 rules**. The committed reference script
uses SciPy's public API and needs no network access or upstream source file.

## Limits

These checks establish the listed binary64 rules and their polynomial moments,
not an error estimate for arbitrary integrands. Rules with signed weights may
suffer cancellation. No extra precision, adaptive sphere integrator, C ABI,
or language wrapper is added. Only the listed Windows/GNU compiler environment
was tested. See the [API guide](../docs/lebedev.md).
