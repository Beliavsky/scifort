# N-dimensional COO sparse arrays (`scipy.sparse.coo_array` subset)

The `scifort_sparse_coo_nd` module stores real binary64 coordinate arrays of
**any positive rank**. A `coo_nd_array` has three allocatable public components:

- `shape(:)` — dimension extents, including zeros.
- `coords(:,:)` — shape `(ndim,nnz)`; **one-based** integer coordinate vectors.
- `data(:)` — stored real(dp) values, including duplicates and explicit zeros.

Constructors preserve input entry order. In-place `coo_nd_sum_duplicates`
uses a stable O(nnz log nnz) merge sort and ascending C-order coordinates,
retaining explicit zeros generated by cancellation. `coo_nd_eliminate_zeros`
removes stored zeros but does **not** aggregate duplicates.

## Interface

| Fortran API | Semantics |
|---|---|
| `coo_nd_from_triplets(dims,coordinates,values,info)` | Copy arbitrary-rank COO coordinates, allowing unsorted duplicates and zeros |
| `valid_coo_nd(a)` | Validate shape, coordinate bounds, data buffers, finite values |
| `coo_nd_is_canonical(a)` | Test strictly increasing C-order coordinates, no duplicates |
| `coo_nd_get(a,indices,info)` | Sum all stored entries at a one-based coordinate; zero if absent |
| `coo_nd_sum_duplicates(a,info)` | Transactional in-place canonicalization; reject overflow |
| `coo_nd_eliminate_zeros(a,info)` | Remove entries whose stored value is exactly zero |
| `coo_nd_transpose(a,axes,info)` | Return permuted axes; default reverses axes; `axes` uses **one-based** indices |
| `coo_nd_reshape(a,new_shape,order,info)` | Preserve all stored entries while reindexing; `order='C'` (default) or `'F'` |
| `coo_nd_from_coo(a,info)` / `coo_nd_to_coo(a,info)` | Lossless conversion to/from existing two-dimensional `coo_matrix` (2D only) |
| `coo_nd_from_dense(dense,info)` | Convert an assumed-rank dense array (ranks 1 through 7), skipping zeros |
| `coo_nd_to_dense(a,dense,info)` | Populate a **preallocated**, matching-shape assumed-rank dense array (ranks 1 through 7) |
| `coo_nd_to_dense_flat(a,info,order,max_elements)` | Return a 1-D dense buffer flattened in C- or F-order |
| `coo_nd_from_dense_flat(dims,flat,info,order)` | Convert a 1-D dense buffer and explicit shape to canonical COO |

`info=0` is `sparse_success`; `info=1` is `sparse_invalid_input`.
For failed constructors or transformations, the result's allocatable components
remain unallocated. Failed `coo_nd_sum_duplicates` does not alter its input.
Nonfinite inputs and nonfinite aggregated values are rejected.

Sparse-only operations do not construct dense intermediates. To prevent
accidental multi-gigabyte allocation, `coo_nd_to_dense_flat` has a default
**10,000,000-element** output limit; callers may raise or lower it with the
`integer(int64)` `max_elements` argument. Shapes with a total size above
`huge(int64)` may exist as sparse arrays, but are rejected by operations that
must compute a flat index (`reshape` and dense flattening).

## Example

```fortran
program coo_nd_example
    use scifort_kinds, only : dp
    use scifort_sparse_coo_nd, only : coo_nd_array, coo_nd_from_triplets, &
        coo_nd_sum_duplicates, coo_nd_transpose, coo_nd_reshape, &
        coo_nd_to_dense_flat
    implicit none
    type(coo_nd_array) :: a, b
    real(dp), allocatable :: flat(:)
    integer :: info

    ! Shape 2x3x4, duplicate coordinates and an explicitly stored zero.
    a = coo_nd_from_triplets([2,3,4], reshape([1,2,2, 1,2,2, 2,1,4], [3,3]), &
                             [2.0_dp,3.0_dp,0.0_dp], info)
    if (info /= 0) error stop 'COO constructor failed'
    call coo_nd_sum_duplicates(a,info)
    if (info /= 0) error stop 'COO aggregation failed'
    b = coo_nd_transpose(a,[3,1,2],info)
    b = coo_nd_reshape(b,[4,6],status=info)
    flat = coo_nd_to_dense_flat(b,info)
    if (info /= 0) error stop 'COO dense conversion failed'
    print *, sum(flat)
end program
```

**C/F-order note:** `coo_nd_to_dense_flat` defaults to C-order (rightmost
axis varies fastest), matching NumPy's default `ravel()`. To obtain the layout
used by native Fortran `reshape`, supply `order='F'`. The assumed-rank
`coo_nd_from_dense` and `coo_nd_to_dense` entry points handle Fortran memory
ordering automatically.

## Validation

```console
python tools/sparse_reference/compare_sparse_coo_nd_scipy.py --mode both --trials 300 --seed 20261105
python tools/sparse_reference/compare_sparse_coo_nd_scipy.py --mode both --trials 250 --seed 274829
python tools/sparse_reference/run_native_sparse.py --mode both
```

All **1,100 independent SciPy 1.17 comparisons** across two compiler modes
passed. See the [validation log](sparse_coo_nd_validation_2026-11-05.md). They include ranks 1–7, zero dimensions, singleton dimensions,
unsorted repeated coordinates, duplicate cancellation, explicit zeros,
canonical sort order, dense flattening, C/F reshape, axis permutation,
scalar lookup, and 2D COO round-trips.

Limitations: real binary64 only. Integer, inclusive-slice, and index-array
selection plus pointwise gathering are provided by the companion
[`scifort_sparse_coo_nd_index`](sparse_coo_nd_index.md) module.
Axis reductions, broadcasting, elementwise arithmetic and tensor contraction
are available through the companion
[`scifort_sparse_coo_nd_ops`](sparse_coo_nd_ops.md) module. The existing 2D CSR/CSC matrices
remain separate types and cannot represent higher-dimensional arrays.

Boolean masks, coordinate scatter assignment, and additive scatter are supported in [the COO N-D edit module](sparse_coo_nd_edit.md).

Sparse predicates and coordinate-set selection (without dense masks) are
documented in [the N-dimensional COO filter module](sparse_coo_nd_filter.md).
