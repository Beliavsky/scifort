# Rank-independent spectral estimators

`scifort_signal` exports the caller-output subroutines `periodogram_into`,
`welch_into`, `csd_into`, and `coherence_into`. They extend the existing
one-dimensional SciPy-style estimators to real/complex arrays of ranks 1–15,
using the existing window, detrending, FFT, and spectral-averaging kernels.

## API

```fortran
use scifort_signal, only : dp, welch_into, csd_into, spectral_status_success
real(dp) :: samples(48,3), power(25,3)
real(dp), allocatable :: freq(:)
integer :: status

! Three signals are stored in the columns of samples.
call welch_into(samples, power, freq, fs=100.0_dp, nperseg=32, &
    noverlap=16, nfft=48, axis=1, average='median', status=status)
if (status /= spectral_status_success) error stop 'Welch failed'
```

`periodogram_into(x, result, frequencies, fs, window, nfft, detrend,
scaling, axis, status)` and `welch_into(x, result, frequencies, fs,
window, nperseg, noverlap, nfft, detrend, scaling, average, axis,
status)` write **real** spectral powers for real or complex `x`.

`csd_into(x, y, result, frequencies, fs, window, nperseg, noverlap, nfft,
detrend, scaling, average, axis, status)` writes **complex** cross-spectral
powers. `coherence_into(x, y, result, frequencies, fs, window, nperseg,
noverlap, nfft, detrend, axis, status)` writes **real** coherence. Both
accept all four combinations of real and complex `x` and `y`. Paired arrays
may have different lengths along the transform axis; the shorter signal is
zero-padded by the existing one-dimensional CSD/coherence implementation.

- The axis is **one-based** (`1`, `2`, ...) or negative (`-1` is the last
  dimension); it defaults to `-1`. This differs from SciPy's zero-based
  positive axes.
- The output rank is the **same as the input rank**, and all non-transform
  dimensions are preserved. The selected dimension is replaced with the
  frequency count. Both inputs to a cross estimator must have matching
  non-transform dimensions. The caller must allocate `result` correctly.
- Real-only signals produce `nfft/2+1` one-sided frequency bins. Any complex
  input produces `nfft` two-sided bins, ordered like `numpy.fft.fftfreq`.
- `welch_into` and `csd_into` support `average='mean'` (default) and
  `average='median'`, plus density or spectrum normalization. The window
  names and other options are passed to the existing SciFort 1-D methods.
- `status=0` means success. On invalid axes, incompatible extents, invalid
  spectral options, or failed channel processing, the routine returns the
  established `spectral_status_invalid_input` and **leaves the entire
  caller-provided `result` unchanged**. `frequencies` is allocated to length
  zero on failure. Strided input/output array sections are accepted.
- The implementation stages a flattened complex copy of input and output
  arrays before committing results. This favors maintenance and guarantees
  all-or-nothing writes, but can require substantial extra memory for large
  arrays. Empty dimensions are currently rejected.

For a rank-15 input, these methods still return rank-15 arrays because they
**replace** (rather than insert) the chosen dimension with frequency bins.
These routines provide SciFort's higher-rank analogue of SciPy's
`axis=` argument. Existing array-returning, rank-one `periodogram`,
`welch`, `csd`, and `coherence` interfaces are unchanged.

## Validation and reproducibility

`test/test_signal_spectral_nd.f90` checks the public module, median
averaging, selected axes, rank-15 inputs, real/complex/mixed CSD,
noncontiguous array sections, unequal input lengths, and failure behavior.

`validation/reference_drivers/reference_signal_spectral_nd.f90` is generated by
`scripts/gen_signal_spectral_nd_reference.py`. Compile it alongside the
`scifort_signal` objects, then run:

```sh
python test/compare_signal_spectral_nd_scipy.py /path/to/reference_signal_spectral_nd
```

This tests 396 combinations across ranks 2, 3, 6 and 15 against SciPy 1.17
spectral calculations on a matrix of independent channels, covering 446,736
spectral values in checked and optimized builds (maximum error below 5e-12).
Near-zero detrended DC bins are excluded **only for
coherence**: numerical roundoff makes their formally indeterminate ratio
very unstable. For the SciPy 1.17 mixed real/complex CSD/coherence reference,
both operands are promoted to complex before asking for a two-sided
spectrum, avoiding an issue in SciPy's one-sided-mode dispatch.

All transforms are independently implemented in Fortran. SciPy and NumPy are
used for optional numerical comparison tests, not as runtime dependencies.

## Parameterized and explicit windows (2026-10-27)

The legacy `*_into` methods now accept four optional trailing keywords:
`window_parameter`, `window_parameter2`, `window_coefficients`, and
`window_values`. These provide named-window shape values and full user-defined
window samples, including `nperseg` inference for the latter. See
[Parameterized windows in legacy spectral estimators](signal_windowed_estimators.md)
for examples, validation rules, and a standalone test command.
