# Remaining SciPy functionality

Initial inventory: 2026-11-11; coverage entries updated 2026-11-18.
This preliminary table summarizes gaps identified from
SciFort's current source, documentation, roadmap, and an initial API-name
comparison. It is not an exhaustive compatibility audit. A matching name or
passing native test does not establish complete SciPy behavior, option,
data-type, dimensionality, accuracy, or performance compatibility.

Some older roadmap entries describe work that has since been completed,
including dependency-backed FPM tests. Verify candidates against current
source and topic guides before starting an implementation.

For the complete list of remaining censored-distribution candidates, see
the [censored distribution coverage inventory](censored_distribution_gaps.md).

| Area | Remaining functionality or compatibility |
| --- | --- |
| FFT | Standalone 1D, 2D, and rank 1-15 multidimensional FFT pairs, DCT/DST types I-IV, selectable axes, frequency bins, shifts, backend-specific fast-length helpers, and [FFTLog fast Hankel transforms](hankel.md) are available in [`scifort_fft`](fft.md). Remaining gaps include workers, public reusable transform plans beyond the existing 1D FFT plan, and backend/option parity. Hankel singular/range handling and wide-bias accuracy limits are documented. |
| Integration | Some QMC integration options. All 32 [Lebedev sphere rules](lebedev.md) are now available. Native real/complex [`solve_bvp`](bvp.md) now covers adaptive two-point systems, unknown parameters, singular terms, analytic Jacobians, and dense output; large-system backend and iteration-path parity remain limited. |
| Interpolation | Native fixed-knot [spherical least-squares splines](interpolate_sphere.md), [scattered spherical smoothing](interpolate_smooth_sphere.md), and [rectangular spherical splines](interpolate_rect_sphere.md) (interpolation and adaptive smoothing, with pole options) are available within documented limits. Additional spline-construction APIs, larger-problem limits, and broader rank-deficient compatibility audits remain. Native real/complex [AAA rational approximation](interpolate_aaa.md) is available; its poles, zeros, residues, and cleanup now support up to 512 retained support points, with documented conditioning limits. Native nonperiodic scalar `splrep(s>0)` and parametric `splprep(s>0)` provide automatic-knot weighted smoothing for degrees 1-5. Native scalar `splrep(per=.true.)` and parametric `splprep(per=.true.)` also provide periodic interpolation and smoothing; additional automatic-knot fitting interfaces still rely on the optional FITPACK backend. Native object-returning `make_splrep` and [parametric `make_splprep`](interpolate_make_splprep.md) add interpolation and automatic/fixed-knot smoothing within documented limits. Both constructors also support [periodic interpolation and automatic/supplied-knot smoothing](interpolate_periodic_constructors.md) for closed input. Both constructors now support [nonclamped exterior knots and rank-deficient regularized fits](interpolate_fixed_general.md) within dense-fallback limits. Legacy periodic [`task=-1` fixed-knot least squares](interpolate_periodic_lsq.md) is also native for scalar and parametric tuples, within documented dense-solver limits. Native [`generate_knots`](interpolate_generate_knots.md) now provides scalar/shared-channel nonperiodic and periodic adaptive knot sequences, with soft stopping counts and documented size/range limits and periodic differences. Both modern constructors now [use this selection and soft counts](interpolate_modern_selection.md) within the generator limits, with explicit infeasible-target failure and retained legacy coverage for larger inputs. [Banded large-input selection](interpolate_large_selection.md) extends this to 10,000 sites and 256 channels, with bounded dense rank fallback. Repeated interiors in supplied-knot modern constructors are now a [SciFort extension](interpolate_repeated_knots.md); SciPy v1.18.0 smoothing rejects them, so their former listing as a missing shared feature was inaccurate. Native tuple [`task=1` continuation](interpolate_continuation.md) now uses caller-owned state for scalar/parametric and ordinary/periodic fits. The known [short cyclic scalar smoothing failure](../validation/periodic_short_basis_2026-11-14.md) is corrected. [Modern near-least-squares smoothing](interpolate_modern_root.md) now samples finite penalties instead of prematurely returning the unpenalized fit. Modern selection/soft counts beyond those limits, broader periodic numerical reliability, and general periodic selection/root-iteration parity remain gaps. |
| Optimization | Stored sparse Jacobians and worker parallelism in least squares; stronger sparse LP/MILP capabilities; SciPy-equivalent SHGO homology stopping and sampling options. |
| Special functions | Native [complex Riemann zeta](complex_zeta.md) and [complex Bessel Y zeros](complex_bessel_zeros.md) are available within documented limits. Higher-imaginary-argument zeta coverage and a broader function-by-function complex-domain/option audit remain; the three Y-zero helpers support up to 1000 complex roots with explicit companion-sign and ordering details. |
| Statistics | Censored likelihoods and bounded fits are available for normal, exponential, minimum/maximum Weibull, Rayleigh, lognormal, Gibrat, gamma, Erlang, beta, Cauchy, symmetric/asymmetric Laplace, log-Laplace, Pareto, Lomax, Fisk, Burr III/XII, uniform, power-function, arcsine, Bradford, triangular, trapezoidal, double-gamma, double-Weibull, log-gamma, inverse-gamma, beta-prime, Maxwell, power-normal, power-lognormal, skew-Cauchy, exponential-power, exponentiated Weibull, Mielke, fatigue-life, Johnson SU, generalized exponential, cosine, anglit, semicircular, truncated exponential, Johnson SB, kappa3, log-uniform, truncated Pareto, generalized half-logistic, folded normal, folded Cauchy, generalized Pareto, generalized normal, half generalized normal, R distribution, chi-squared, chi, Nakagami, Student t, F, Jones-Faddy skew-t, inverse Gaussian, Wald, reciprocal inverse Gaussian, generalized gamma, truncated normal, truncated Weibull, alpha, generalized extreme value, Crystal Ball, ARGUS, Pearson III, kappa4, Gauss hypergeometric, Irwin-Hall, real-line von Mises, exponentially modified normal, skew-normal, double Pareto-lognormal, Rice, noncentral chi-squared, noncentral F, wrapped Cauchy, asymptotic Kolmogorov, relativistic Breit-Wigner, generalized inverse Gaussian, normal-inverse Gaussian, generalized hyperbolic, noncentral Student t, Landau, Levy-stable, studentized range, Tukey lambda, one-sided and two-sided finite-sample Kolmogorov-Smirnov, fixed-branch von Mises (a SciFort extension), generalized logistic, Gompertz, inverse Weibull, Moyal, Levy and reflected Levy, logistic, half-Cauchy, half-logistic, half-normal, hyperbolic-secant, and both Gumbel distributions (lognormal/Gibrat/gamma/Erlang fits require fixed location, beta fits require fixed location and scale, and gamma/Erlang/beta fits exclude exact support endpoints); all 109 named continuous fitting families now have censored methods. Levy-stable and studentized-range methods retain documented restricted shape/coordinate domains; extending those domains remains. Student t/F/Jones-Faddy censoring requires normal positive beta shapes with sum at most 1e6 (Student t also accepts infinite df); extending those ranges remains. Chi/chi-squared censoring requires df<=2e6 and a positive representable half-shape; Nakagami censoring requires nu<=1e6; generalized-normal censoring requires a finite reciprocal power; R censoring currently limits shape to 1e6 and requires representable half-shape/affine support. Wrapped-Cauchy censoring uses a fixed coordinate interval with documented shape/affine limits; crossing-boundary arcs remain separate. Relativistic Breit-Wigner censoring requires rho in [0.1,100]. Rice/noncentral chi-squared/noncentral F censoring has finite shape limits and a 10,001-term convergence guard. Exponentially modified normal, skew-normal, double Pareto-lognormal, Gauss hypergeometric, Irwin-Hall, real-line von Mises, ARGUS, Pearson III, kappa4, alpha, GEV, and Crystal Ball censored methods also have documented finite shape limits. Extending these numerical ranges, observation weights, and additional method/option compatibility remain. See [censored fitting](censored_fitting.md). Distribution-name coverage alone does not establish complete compatibility. |
| Sparse graphs | Native sparse weighted full matching is available as `min_weight_full_bipartite_matching` and the original `minimum_weight_full_bipartite_matching`; see [graph compatibility details](sparse_csgraph.md). Additional graph conversion helpers and input-format/option parity remain. |
| Linear algebra | Broader batching, larger-problem backends, stronger conditioning/error handling, and condition estimates. Native [real QZ and ordered blocks](linalg_real_qz.md) now cover orders 0..40. Most major algorithm families already exist. |

C ABI coverage and the planned Python, R, MATLAB, and Octave wrappers also
remain incomplete. These are interoperability tasks distinct from implementing
numerical algorithms. Current work prioritizes native Fortran SciPy coverage;
C ABI and wrapper expansion are deferred.

For the project's statistics-first objective, prioritize distribution fitting,
special-function gaps, and a current function-by-function compatibility inventory
before expanding into additional SciPy subpackages. New scope remains subject
to the approval requirements in [repository rules](../AGENTS.md).
